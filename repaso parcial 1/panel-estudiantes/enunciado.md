# EJERCICIO DE REPASO — PANEL DE ESTUDIANTES

## CONTEXTO DEL EJERCICIO
Crear una página web llamada **"Panel de Estudiantes"** para registrar estudiantes y practicar todos los conceptos integradores de Programación 4:
- HTML, CSS, Bootstrap 5
- Variables, tipos de datos, operadores
- Condicionales (`if / else if / else`)
- Bucles (`for` y `while`)
- Funciones
- Arrays y Objetos
- Métodos de arrays `map()` y `filter()`
- Fechas con `Date` y temporizadores con `setInterval()`
- Manipulación del DOM y Eventos
