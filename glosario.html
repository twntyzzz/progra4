1. Componentes de Bootstrap 5

1.1 Botones (Colores, Anchos y Outlines)

Se usan con onclick="nombreFuncion()" para ejecutar acciones en JavaScript.

Botones al 50% de ancho en la misma fila (usando d-flex gap-2):

Código HTML:
<!-- Botón principal (Probar, Calcular, Guardar) -->
<button class="btn btn-primary" onclick="calcular()">Calcular</button>

<!-- Botón verde de éxito -->
<button class="btn btn-success" onclick="lanzar()">Lanzar Dados</button>

<!-- Botón rojo de peligro o limpiar -->
<button class="btn btn-danger" onclick="limpiar()">Limpiar</button>

<!-- Dos botones al 50% de ancho en la misma fila -->
<div class="d-flex gap-2">
    <button class="btn btn-primary w-50" id="btnProbar" onclick="probar()">Probar</button>
    <button class="btn btn-danger w-50" onclick="reiniciar()">Reiniciar</button>
</div>

<!-- Botón de ancho completo -->
<button class="btn btn-success w-100" onclick="ejecutar()">Ejecutar Todo</button>
1.2 Alertas (Mensajes de Estado)

Las alertas se usan para mostrar resultados de aciertos (verde), fallos (rojo), advertencias de validación (amarillo) e información (celeste).

alert-success (Verde): ¡Acertaste! El número era 73.
alert-danger (Rojo): No acertaste. El número era 73.
alert-warning (Amarillo): Ingresa un número válido entre 1 y 100.
alert-info (Celeste): Te pasaste. / Te faltó. / Lanzando...
HTML y manipulación con JavaScript:
<!-- 1. En el HTML: Alerta oculta inicialmente con 'd-none' -->
<div id="mensaje" class="alert d-none mt-3" role="alert"></div>

// 2. En JavaScript: Cambiar mensaje y color según la condición
let mensaje = document.getElementById("mensaje");

// Si acertó (Verde):
mensaje.className = "alert alert-success";
mensaje.innerText = "¡Acertaste! El número era " + numeroSecreto;

// Si falló / perdió (Rojo):
mensaje.className = "alert alert-danger";
mensaje.innerText = "No acertaste. El número era " + numeroSecreto;

// Si ingresó dato inválido (Amarillo):
mensaje.className = "alert alert-warning";
mensaje.innerText = "Ingresa un número válido entre 1 y 100.";

// Para ocultarla de nuevo al reiniciar:
mensaje.className = "alert d-none";
mensaje.innerText = "";

3.2 Validaciones y Condicionales (if / else / switch) 
// 1. Validar si está vacío o fuera del rango (1 a 100):
let numero = parseInt(document.getElementById("numero").value);

if (isNaN(numero) || numero < 1 || numero > 100) {
    let mensaje = document.getElementById("mensaje");
    mensaje.className = "alert alert-warning";
    mensaje.innerText = "Ingresa un número válido entre 1 y 100.";
    return; // IMPORTANTE: return detiene la función para NO gastar intento
}

// 2. Condicional para comparar números:
if (numero === numeroSecreto) {
    // Acertó
} else if (numero > numeroSecreto) {
    // Te pasaste
} else {
    // Te faltó
}

// 3. Estructura SWITCH (usada en la calculadora):
switch (operacion) {
    case "suma":
        resultado = num1 + num2;
        break;
    case "resta":
        resultado = num1 - num2;
        break;
    case "multiplicacion":
        resultado = num1 * num2;
        break;
    case "division":
        if (num2 !== 0) {
            resultado = num1 / num2;
        } else {
            resultado = "No se puede dividir por cero";
        }
        break;
    default:
        resultado = "Operación no válida";
}

3.4 Temporizadores y Animaciones (setInterval, setTimeout) 
// 1. setInterval: ejecuta código REPETIDAMENTE cada X milisegundos
let animacion = setInterval(function () {
    // Cambia los números de los dados cada 50 milisegundos
    document.getElementById("dado1").innerText = Math.floor(Math.random() * 6) + 1;
    document.getElementById("dado2").innerText = Math.floor(Math.random() * 6) + 1;
}, 50);

// 2. setTimeout: ESPERA X milisegundos y se ejecuta UNA SOLA VEZ
setTimeout(function () {
    // 3. clearInterval: Apaga la repetición del intervalo
    clearInterval(animacion);

    // Mostramos el resultado final
    let dado1 = Math.floor(Math.random() * 6) + 1;
    let dado2 = Math.floor(Math.random() * 6) + 1;
    let total = dado1 + dado2;

    document.getElementById("dado1").innerText = dado1;
    document.getElementById("dado2").innerText = dado2;
    document.getElementById("total").innerText = "Total: " + total;
}, 2000); // 2000 ms = 2 segundos
3.5 Bucles (For y While) 
// Bucle FOR (imprimir números del 1 al 10):
for (let i = 1; i <= 10; i++) {
    document.getElementById("lista").innerHTML += `<li class="list-group-item">Número ${i}</li>`;
}

// Bucle WHILE (números pares del 1 al 20 usando módulo %):
let i = 1;
while (i <= 20) {
    if (i % 2 === 0) { // i % 2 === 0 significa que es divisible por 2 (es par)
        document.getElementById("listaPares").innerHTML += `<li class="list-group-item">Par: ${i}</li>`;
    }
    i++;
}
